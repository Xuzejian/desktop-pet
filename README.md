# 毛球 · Windows 桌面宠物

一只可以拖动、摸摸、喂食和陪你散步的毛茸茸小猫。适用于 **Windows 10 / 11，64 位（x64）**。

解压后双击 `FluffyPet.exe` 即可运行，无需安装 Python、浏览器或其他运行环境。内置猫咪图片已经打包进程序，单独保留 EXE 也可以运行。程序离线运行，不会自动设置开机启动。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 单击猫咪 | 摸摸它，显示爱心和回应；为区分双击，会稍等片刻 |
| 按住左键拖动 | 移动猫咪，松手后留在当前屏幕范围内 |
| 双击猫咪 | 睡觉 / 叫醒 |
| 右键猫咪 | 打开互动和设置菜单 |
| 双击系统托盘中的猫咪图标 | 重新显示猫咪 |
| 右键托盘图标 | 打开同一个菜单 |

右键菜单提供：摸摸我、喂小鱼干、逗猫跳跃、睡觉或叫醒、自动散步开关、小 / 中 / 大三种尺寸、总在最前面、自定义外形、恢复内置猫咪、隐藏到托盘、使用说明和退出。“恢复照片猫咪”只在已导入外形时显示。

默认开启自动散步和置顶。猫咪会在当前屏幕的可用区域内水平移动；互动和睡觉时暂停散步。想让它固定陪在一个位置，取消勾选“自动散步”即可。隐藏后可在任务栏的托盘区域（有时在折叠菜单中）双击图标找回；再次运行 EXE 也会显示已经运行的猫咪。

## 换成自己的图片

右键选择“自定义外形…”，导入 PNG、JPG、JPEG 或 BMP，宽高均不能超过 8192 像素。**推荐透明背景 PNG**：普通照片会完整保留背景，程序不会自动抠图。

程序记录图片的原路径，不会复制图片。请把图片留在固定位置；移动或删除后，下次启动会使用内置猫咪。导入图片只有一个外形，互动时仍有移动、弹跳等效果，睡觉时会显示睡眠效果，但不会生成新的闭眼姿势。内置猫咪拥有单独的睡眠图片。

## 设置与移除

位置、尺寸、散步、置顶和自定义图片路径保存在：

```text
%LOCALAPPDATA%\FluffyDesktopPet\settings.ini
```

恢复全部默认设置：先从菜单退出程序，再删除这个 `settings.ini`。菜单中的“恢复照片猫咪”仅恢复内置外形。移除程序时，退出后删除 EXE；如不需要保留设置，可一并删除上述 `FluffyDesktopPet` 文件夹。
